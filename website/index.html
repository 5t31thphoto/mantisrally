Mantis Rallyan infinite stage that dreams itself

Tip the Core2 forward to gas, pull back to brake, tilt to steer, hold C for the handbrake. Seventeen biomes, branching roads, drifts that stick. Everything is made live on the device.

Stages

Twelve biomes and the roads between them: pine forest, redwood cathedral, lake country, rain moor, Devil’s Pass, alpine summit, red canyon, coast highway, wildflower meadow, autumn ridge, bayou mud and frost tundra. Weather wanders, the day turns, and every fork names where it leads.

Mantis Rally joins MantisPlanet and Mantis Seadiver. Built for M5Stack Core2. Firmware is produced by GitHub Actions and served from this page.
